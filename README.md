# QUOTATION-MAKER
I work as salesman for a material handling company, and we need to type in our quotation manually here, so i try to come up with a solution by making a program that can generate quotation.

How to run
1. Extract ZIP (has to be new independent folder).
2. Python 3 must have installed.
3. Double click run.bat.
4. Browser will run the app.

Note:
i use libre office as the file generator and converter because is more stable. But, if you dont have libre installed, the program will try to use Microsoft office. Crashes sometime happened when it uses Microsoft office.
